This library allows an Arduino board with USB capabilities to act as a keyboard.

For more information about this library please visit us at
https://www.arduino.cc/reference/en/language/functions/usb/keyboard/

== Installation ==

=== Automatic installation ===

==== Windows ====

. Download better-hid-keyboard-{version}.zip from the Releases page
. Open Command Prompt
. Run these commands:
+
[source,batch,subs="attributes+"]
----
tar -xf "%USERPROFILE%\Downloads\better-hid-keyboard-{version}.zip" -C "%userprofile%\Documents\Arduino\libraries"
del "%USERPROFILE%\Downloads\better-hid-keyboard-{version}.zip"
----

==== Linux ====

. Download better-hid-keyboard-{version}.tar.gz from the Releases page
. Open the terminal
. Run these commands:
+
[source,bash,subs="attributes+"]
----
tar -xzf "$HOME/Downloads/better-hid-keyboard-{version}.tar.gz" -C "$HOME/Arduino/libraries"
rm "$HOME/Downloads/better-hid-keyboard-{version}.tar.gz"
----

=== Manual installation ===

. Download better-hid-keyboard-{version}.zip for Windows or .tar.gz for Linux
. Extract the downloaded archive
. Copy the extracted HID_Keyboard folder into C:\Users\<username>\Documents\Arduino\libraries for Windows or /home/<username>/Arduino/libraries for Linux
. Delete the original archive and extracted folder
